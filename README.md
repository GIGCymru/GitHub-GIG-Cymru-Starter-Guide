# GitHub GIG Cymru Handbook

The handbook for how NHS Wales organisations use GitHub. Read it online at
<https://gigcymru.github.io/GitHub-GIG-Cymru-Starter-Guide/>.

## Edit locally

Content lives in `docs/`; navigation is in `mkdocs.yml`.

```bash
pip install -r requirements.txt
mkdocs serve   # http://127.0.0.1:8000
mkdocs build --strict
```
