# GitHub GIG Cymru Handbook

Welcome to the **GitHub GIG Cymru Handbook** — the single source of truth for how NHS Wales
organisations use GitHub in practice.

This handbook is modelled on the
[Azure DevOps Handbook](https://gigcymru.github.io/dhcw-software-engineering-handbook/azure-devops-handbook/introduction/)
and covers everything from initial access through to security, automation, and integration
with Azure DevOps.

---

## About GitHub GIG Cymru

GitHub GIG Cymru is a secure, centrally managed GitHub Enterprise platform provided by NHS
Wales. It enables organisations to:

- **Develop under a community umbrella** — Each organisation gets its own GitHub organisation,
  fostering collaboration and knowledge sharing across NHS Wales.
- **Leverage enterprise features** — Advanced security (GHAS), compliance tooling, and
  management controls.
- **Collaborate securely** — Work with colleagues across NHS Wales in a trusted environment.
- **Accelerate digital transformation** — Share code, automate workflows, and build solutions
  together.
