# Introduction

## Purpose

This opinionated guide explains how to use **GitHub GIG Cymru** — the NHS Wales national
GitHub Enterprise solution — to manage software projects. It is the single source of truth
for how we use GitHub in practice across NHS Wales organisations.

If you are new to GitHub or version control in general, start with the official learning
path:

> **Further reading and information**
> [Introduction to GitHub - GitHub Skills](https://skills.github.com/)
>
> [GitHub Foundations certification learning path - Microsoft Learn](https://learn.microsoft.com/en-gb/collections/o1njfe825p602p)
>
> [GitHub for beginners - GitHub Docs](https://docs.github.com/en/get-started)

## Scope

### In-scope

- Good practices for using GitHub core and advanced features within NHS Wales.
- Recommended conventions and naming standards.
- How to integrate GitHub with Azure DevOps.
- Essential [good practice checklist](essential-good-practice-checklist.md).

### Out-of-scope

- Creating or configuring a new GitHub organisation (contact the GitHub GIG Cymru service team).
- Adding external collaborators from outside NHS Wales.
- Integrating third-party software not covered in this guide.
- Foundational DevOps theory such as branching strategies or CI/CD concepts in general.

## Conventions

The key words **MUST**, **MUST NOT**, **REQUIRED**,
**SHALL**, **SHALL NOT**, **SHOULD**, **SHOULD NOT**,
**RECOMMENDED**, **MAY**, and **OPTIONAL** in this document are to be
interpreted as described in [RFC 2119](https://www.ietf.org/rfc/rfc2119.txt).

> **Practical tips** are provided throughout this guide to highlight recommended patterns.

> **Examples of good practice** show real-world naming and configuration examples.

> **Practices to avoid** highlight common mistakes and anti-patterns.

> **Further reading and information** links to official GitHub documentation and NHS Wales resources.

## The need for guidance

GitHub GIG Cymru is used daily by staff across multiple NHS Wales organisations. Following
good practice is essential to ensure consistent, secure, and maintainable use of the platform.

This guide helps you plan, build, and release software in a way that enables seamless
coordination across teams and organisational boundaries — while keeping NHS Wales data safe.
